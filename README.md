# Meshimase（めしませ）

ランチ/夜ご飯を迷わず決められる iOS アプリ。
マスコット「ニャシェフ」がツンデレ口調で料理を提案します。

## ステータス
MVP 実装中（SwiftUI / iOS 17+）

## 構成
- `SPEC.md` - 仕様書
- `Meshimase/` - iOS アプリソース（SwiftUI）
  - `Models/` - データモデル
  - `Views/` - UIレイヤ
  - `Services/` - IAP / 位置情報 / 店舗検索
  - `Resources/` - メニューJSON等

## 開発セットアップ
1. Xcode 15+ で `Meshimase.xcodeproj` を開く
2. 実機 or シミュレータで Run
